# Kumo：免费、开源的 VPN 客户端，支持 Android、Windows、macOS 和 Linux

网站: [kumo-client.ir](https://kumo-client.ir/zh/)

</div>

## Kumo 是什么？

Kumo 是一款免费、开源的 VPN 客户端，支持 Android、Windows、macOS 和 Linux，无需注册账号。它会找到在你的网络上可用的公共服务器，一键连接到最快的那一个。它也能打开你自己的 V2Ray、Xray 和 sing-box 配置与订阅（VLESS、VMess、Trojan、Shadowsocks、Hysteria2、WireGuard 等），与其他 V2Ray 和 sing-box 客户端使用相同的链接。Kumo 基于 [sing-box](https://github.com/SagerNet/sing-box) 和 [Xray](https://github.com/XTLS/Xray-core)。

## 功能

- 一键连接，自动选择最快的服务器，服务器无响应时自动切换。
- 整台设备（Android）或本地代理；按应用分流、直连国家、自定义路由规则。
- 免费公共服务器，你自己的配置和订阅（链接、二维码、文件；Clash、sing-box、Xray 和 Surge 格式）。
- 多种协议：VLESS、VMess、Trojan、Shadowsocks、Hysteria 1 和 2、TUIC、AnyTLS、WireGuard、SOCKS、SSH 等。
- 隐私：kill switch、严格 DNS、阻止 WebRTC 泄露、拦截广告和跟踪器、IP 和 DNS 泄露测试。
- 测速、实时速度和流量、小组件、托盘图标、Android TV、七种语言。

## 使用方法

1. 打开 Kumo，等待服务器列表加载。
2. 点击连接按钮（*自动* 会选择最快的服务器）。
3. 在 Android 上，首次使用时允许 VPN 权限。

## 须知

- 公共服务器由不明身份的人运营。**不要用它们进行网上银行或任何敏感操作。**
- Kumo 没有账号，也看不到你的任何服务器、链接或流量。它每天发送一次匿名使用统计：一个由设备 ID 生成、看起来随机的代码，以及系统和应用版本、应用语言、设备的语言和国家设置、时区、处理器、设备厂商和型号（如 *Dell XPS 15*）、你安装的文件名（如 `kumo-android-universal.apk`），在 Android 上还有手机的系统界面，在 Linux 上还有桌面环境（不保存 IP 地址、序列号或计算机名）。如果出现故障，Kumo 也可以通过同一个开关发送崩溃报告：错误及其在代码中的位置、Kumo 和系统版本、设备厂商和型号、你所在的页面、VPN 状态以及应用自身日志的最后几行，其中的链接、地址、密码和用户名都会被移除。两者都可以在 *设置 → 应用设置* 中关闭。参见[隐私政策](PRIVACY.md)。

## 从源码构建

Flutter 3.27（Dart 3.6）：`flutter pub get`、`flutter test`。sing-box 和 Xray 内核不在仓库中：`tools/fetch_unix_core.sh`（Linux、macOS）、`tools/fetch_windows_core.ps1`（Windows）、`tools/build_libbox.ps1` 和 `tools/build_xray.ps1`（Android）。完整的构建过程见 `.github/workflows/build.yml`。
