# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use **Report a vulnerability** on the
[Security tab](../../security/advisories/new) of this repository so the report stays private.

Include what you found, the version, and steps to reproduce it. You will get an answer as soon as
possible, and credit in the release notes if you want it.

## Supported versions

Only the latest release gets fixes.

## Scope

Kumo connects to servers that its users choose. Public servers are run by third parties and are
not part of Kumo; a weakness of such a server is not a vulnerability of the app.
