## Kumo 是什麼？

Kumo 是一款免費、開源的 VPN 用戶端，支援 Android、Windows、macOS 和 Linux，不需要註冊帳號。它會找出在你的網路上可用的公共伺服器，一鍵連線到最快的那一台。它也能開啟你自己的 V2Ray、Xray 和 sing-box 設定與訂閱（VLESS、VMess、Trojan、Shadowsocks、Hysteria2、WireGuard 等），與其他 V2Ray 和 sing-box 用戶端使用相同的連結。Kumo 以 [sing-box](https://github.com/SagerNet/sing-box) 和 [Xray](https://github.com/XTLS/Xray-core) 為核心。

## 功能

- 一鍵連線，自動選擇最快的伺服器，伺服器無回應時自動切換。
- 整台裝置（Android）或本機代理；依應用程式分流、直連國家、自訂路由規則。
- 免費公共伺服器，你自己的設定和訂閱（連結、QR 碼、檔案；Clash、sing-box、Xray 和 Surge 格式）。
- 多種協定：VLESS、VMess、Trojan、Shadowsocks、Hysteria 1 和 2、TUIC、AnyTLS、WireGuard、SOCKS、SSH 等。
- 隱私：kill switch、嚴格 DNS、阻擋 WebRTC 洩漏、封鎖廣告和追蹤器、IP 和 DNS 洩漏測試。
- 測速、即時速度和流量、小工具、系統匣圖示、Android TV、七種語言。

## 使用方式

1. 開啟 Kumo，等待伺服器清單載入。
2. 點選連線按鈕（*自動* 會選擇最快的伺服器）。
3. 在 Android 上，第一次使用時允許 VPN 權限。

## 注意事項

- 公共伺服器由身分不明的人經營。**不要用它們進行網路銀行或任何敏感的事。**
- Kumo 沒有帳號，也看不到你的任何伺服器、連結或流量。它每天傳送一次匿名使用統計：一個由裝置 ID 產生、看起來隨機的代碼，以及系統和應用程式版本、應用程式語言、裝置的語言和國家設定、時區、處理器、裝置廠商和型號（例如 *Dell XPS 15*）、你安裝的檔案名稱（例如 `kumo-android-universal.apk`），在 Android 上還有手機的系統介面，在 Linux 上還有桌面環境（不儲存 IP 位址、序號或電腦名稱）。如果發生故障，Kumo 也可以透過同一個開關傳送當機報告：錯誤及其在程式碼中的位置、Kumo 和系統版本、裝置廠商和型號、你當時所在的頁面、VPN 狀態以及應用程式本身記錄的最後幾行，其中的連結、位址、密碼和使用者名稱都會被移除。兩者都可以在 *設定 → 應用程式設定* 中關閉。請參閱[隱私權政策](PRIVACY.md)。

## 從原始碼建置

Flutter 3.27（Dart 3.6）：`flutter pub get`、`flutter test`。sing-box 和 Xray 核心不在儲存庫中：`tools/fetch_unix_core.sh`（Linux、macOS）、`tools/fetch_windows_core.ps1`（Windows）、`tools/build_libbox.ps1` 和 `tools/build_xray.ps1`（Android）。完整的建置流程見 `.github/workflows/build.yml`。
