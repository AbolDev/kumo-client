# Kumo 1.12.0 beta 11 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 10

- **Fix: the update check missed newer test versions.** It compared only the numbers (`1.12.0`) and ignored the suffix, so beta 10 looked the same as beta 9 and the first release in GitHub's list was offered. GitHub lists releases by the text of their names (`beta.10` comes before `beta.5`), which made it show beta 9. Now `beta.10` is newer than `beta.9`, a release candidate is newer than a beta, and the stable release is newer than its test versions.
  - A copy older than this one (beta 10 or before) still has the old check: update it by hand from the release page this once.
