# Kumo 1.11.0

## What's new

- **Free connections.** A new page, opened from the **+** menu (and from Settings), lists the free ways to connect, each with a switch and a *Manage* button. *Public servers* are on, as before. *WARP* is off until you turn it on.
- **Cloudflare WARP (a test feature).** WARP is a free tunnel from Cloudflare. Where a network blocks it, Kumo makes the account with the TLS hello cut into pieces, and sends a few noise packets before the first WireGuard packet, so that the start of the tunnel does not look like WireGuard. WARP has a group of its own in the server list, with the way it connects and how much went through it (like the public servers). *Try another way* switches to the next method, address or port; turning it off takes the group away and keeps the account.
- **Methods that change without a new version.** How WARP connects (addresses, ports, noise, and which methods this version may use) is read from a signed file in the project. Kumo downloads it now and then and only takes a file that is signed by a key it knows, is newer, and has not run out. A copy is built in.
- **Names with flags.** A flag emoji anywhere in a server's name is drawn as a picture on Windows and Linux (it was only drawn when it was the first thing in the name).
- **My IP.** While a VPN is connected, the page no longer asks the Iranian service that answers with your real address, so it shows the VPN's address.
- **Linux.** The rpm of a test version is now built (a dash is not allowed in an rpm version).

## About WARP

WARP was tried on Windows on one network in Iran: sign-up and the connection worked, but the data that follows was slow and often stalled there. It has **not been tried on phones or on other networks** yet (mobile operators filter differently). It is off by default. Please report what you see.
