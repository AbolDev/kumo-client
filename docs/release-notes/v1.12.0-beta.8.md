# Kumo 1.12.0 beta 8 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 7

- **OpenVPN servers can be tested (Windows).** *TCP ping* connects to a TCP server, and asks a UDP server with the first packet of the protocol (a server that only listens to signed packets, `tls-auth` or `tls-crypt`, cannot be told this way and is skipped). *Real delay* runs the OpenVPN program against the server without an adapter and measures the time until the handshake is done, so it changes nothing on the computer. A server that needs a login is skipped.
- **A better password window.** Opening a locked file (`.npvs` and the like) now shows what the window is for and the file's name, has a show/hide button, and tells a wrong password under the field so it can be typed again, instead of closing with an error.
- **Clearer number windows.** The connect timeout, the proxy port, the shared-network port and the MTU now have a label, the range that is allowed and the error under the field. The password window in Settings looks the same, and the buttons that were fixed English letters are translated.
- **The notice on the home screen** (for example "OpenVPN works on Windows only for now") is no longer stuck to the status above it.

OpenVPN on Android is not done yet.
