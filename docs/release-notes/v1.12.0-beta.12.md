# Kumo 1.12.0 beta 12 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 11

- **Anonymous usage count.** Once a day (and again when the version changes) Kumo sends a random-looking code made from your device id, your system and Kumo version, and your country, so the developer can tell how many people use it. It never sends servers, links, browsing or traffic, and no IP address is stored. It is on by default and can be turned off in *Settings → App settings*; turning it off sends one last message and then nothing. The details are in the [privacy policy](https://github.com/AbolDev/kumo-client/blob/main/PRIVACY.md).
  - It is sent in the background and never delays starting or connecting. If the server cannot be reached directly, it tries again with the TLS hello cut into small pieces (as WARP sign-up does), and while the VPN is on, through the tunnel.
