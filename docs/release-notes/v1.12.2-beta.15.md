# Kumo 1.12.2 beta 15 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 14

- **The data used keeps its days.** The statistics of data used (*Live connections > Usage*) and the state of the anonymous usage count were saved in the same file, so each save of one wrote over the other: days were lost, and the choice to send nothing could be forgotten. The count now has a file of its own (what an older version left is moved to it once). A damaged day or server in the statistics is skipped and the rest stays, a file nothing can read is kept aside as `usage.json.broken` instead of being written over, and what the phone's service counted while the app was closed is kept until it is saved. *Reset all* asks first and says it cannot be undone.
- **A server of your own over MASQUE.** `masque://user:pass@host:port?sni=..&alpn=h2|h3&path=..&host=..&fp=..&pcs=..#name` is a server now (a MASQUE server with a login, such as the MASQUE inbound of Xray). It runs on Xray, HTTP/2 by default; the certificate is checked, against the chain or against the SHA-256 given in `pcs`, and a link that asks to skip the check is refused. The configuration was accepted by Xray 26.10.21; no tunnel was run to a server yet, so tell us how it goes.
- **DNS shows the one in use.** In *Settings > Network* the list of DNS servers is one row with the chosen server; tap it to see the others and pick one.
- **Options with a value laid out like the switches.** *Sleep timer*, *Daily data cap*, the interval of subscriptions, *Logs*, the core, the certificate store, the log level, *Connect timeout*, *Network strategy*, *Chain*, *App routing*, *Routing rules* and a few more have an icon in the middle of the row, the value at the end of the title and the description under it with the whole width. The switches of *Kill switch*, *Automatic failover*, *Auto connect*, *Restart when changing settings*, *Delete confirmation* and the usage count have their icon too.
- **Real delay follows the connection.** The *Real delay* item of a menu that stays open while the VPN goes up or down is enabled and disabled with it. The name of a MASQUE server of WARP no longer says "masque" twice.
- **What Xray says is in the log (Android).** The lines Xray writes appear in the app's log with the warnings and errors kept even in a burst of lines, so a connection through Xray that stops can be understood from the log.
- **Fewer false crash reports.** A network error that arrives as text, and an OpenVPN failure the user is told about (login refused, a blocked handshake, a timeout), are no longer sent as crashes; the usage ping and the start of OpenVPN no longer leave an error that nobody caught when a connection is reset.

Everything else is as in [beta 1](https://github.com/AbolDev/kumo-client/releases/tag/v1.12.2-beta.1) to beta 14. The WARP server that fails when connected (*wg-noise-a*, *wg-noise-b*) is not fixed yet: if you see it, send the log (*Settings > Logs*) after a few minutes of connection.
