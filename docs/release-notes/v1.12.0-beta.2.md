# Kumo 1.12.0 beta 2 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings. **Windows only for the new part.**

## What's new since beta 1

- **No driver to install by hand.** OpenVPN needs a network adapter driver (TAP-Windows, from the OpenVPN project, signed through Microsoft's hardware program). It now comes with Kumo (in the `openvpn\driver` folder, checked at build time against a pinned hash and its signature) and is put into Windows by Kumo the first time you connect to an OpenVPN server. Kumo says "installing the network driver" while it does; Windows may ask you to confirm it once. If Windows refuses, Kumo shows what Windows said.

## OpenVPN (a test feature, Windows)

- Add an `.ovpn` file (from the **+** menu: *Add from file* or *Add from clipboard*, with the certificates inside the file). It becomes a server of the type *openvpn* in *Added manually*.
- A file is never run as it is. Kumo reads the lines it knows and writes its own configuration; lines that run programs (`up`, `down`, `route-up`, `plugin`...), open a control port, write files or load other files are left out.
- If the server asks for a user name and password, an *OpenVPN login* window opens (also in the menu of the server).
- Kumo runs the official OpenVPN (signed by OpenVPN Inc., in the `openvpn` folder) and sends everything out through its adapter, so the rules, the DNS, the speed and the usage work as with other servers.
- Not yet: Linux, macOS and Android, tests of the servers' delay, and the *keep the proxy running* mode.

The list of F0rc3Run (a couple of hundred tested servers) is also added to *Public servers*.

## About this test

OpenVPN was tested up to the point of starting the program, the management port, the login, the driver step and the sing-box configuration (accepted by the real core). It has **not yet been tried against a real server** in a build of the app: please report what you see (the log page shows the messages of OpenVPN).
