# Kumo 1.12.0 beta 6 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 5

- **The kept proxy is never closed (desktop).** With *Keep the proxy running* on, Kumo itself now listens on the proxy port and passes each connection to the core that runs at that moment. Connecting, disconnecting and changing the server swap the core behind it: the port stays open, and a new connection waits a moment for the next core instead of being refused. Connections that are going through a core when it stops are still cut. UDP through the shared network (LAN) port may not work. If another program holds the proxy port, the old way is used.
- **"Disconnecting" can no longer stay for good.** Taking the system proxy back and stopping the cores now have time limits; after them the connection is shown as ended.
- **Newer NPV `.npvs` exports open.** Files whose lines hold a name and a v2rayJson (not links) are read, and each server gets its name.

OpenVPN is as in beta 4 (a test feature, Windows only for now).
