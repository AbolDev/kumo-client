# Kumo 1.12.1

## What's new

- **A new app icon.** The default is now a faceted cloud in the app's teal. Twelve icons are in *Settings*; pick the one you like. On Android each icon is its own launcher entry; on Windows the window, taskbar button, tray and the Start menu, desktop and pinned shortcuts take the picked icon. The icons are sharper at every screen scale, and the home page header shows the same cloud.
- **Kumo ID in Settings.** *Settings > App settings* now shows the ID that the anonymous usage count sends instead of your device id, so you can see exactly what is sent. Tap it to copy.

## Fixes

- **Android: no launcher entry after an update.** An update could leave no icon enabled, so the app had no "Open" and could not be started. Kumo now enables the saved icon's entry at every start and right after each update.
- **Windows: old icon on the taskbar.** After an update, a pinned taskbar button and shortcuts kept the icon Windows had cached for `kumo.exe`. The shortcuts now point at the icon file itself and are checked at each start.
