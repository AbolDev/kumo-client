# Kumo 1.12.2 beta 10 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 9

- **"Address already in use" after a disconnect (Android).** The core of the last connection closes in the background and could still hold the proxy port; the next connection waited up to 12 seconds for it and then failed. Now the next core starts beside it at once, with either core (sing-box or Xray). On Linux and macOS a core that does not close when asked is ended after a second (three with the tunnel).
- **A connection does not wait for blocked encrypted DNS.** The name of the server is asked over encrypted DNS alone for 0.4 seconds; then the system's resolver is asked beside it and the first answer is taken (before: a wait of 2.5 seconds where 1.1.1.1 and 8.8.8.8 are blocked).
- **Slow networks (H+, a weak signal).** When the pings show a slow network, the time limits of the ping, the real delay and the check of a running connection grow (up to three times), and fewer pings run at once, so working servers are not called dead and the automatic mode does not leave a server that only needed longer.
- **From the crash reports.** A server with a pinned certificate now starts on Xray (it refused the configuration). A server with a wrong Reality key no longer stops *the fastest servers* from connecting; it is left out. The background update of a subscription (Android) no longer runs out of memory on a huge answer. A rare error of a hint in the server list (Windows) is gone. Errors of the network itself (a connection that was reset, a timeout) are no longer sent as crash reports.
- **Real delay asks at the bottom of the screen**, where the thumb is, and *Remember my choice* makes the next question start with your answer.
- **The notes of an update can be read in another language** on the update page, when they have one.
- **Share Kumo** (*Settings > About*): a message ready to send in the language you pick, and a QR code of Kumo's site.

Everything else is as in [beta 1](https://github.com/AbolDev/kumo-client/releases/tag/v1.12.2-beta.1) to beta 9. Most of it was checked by tests, not on every kind of device, so please tell us what you see.
