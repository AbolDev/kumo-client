# Kumo 1.12.0 beta 9 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 8

- **Locked `.npvs` files open in under a second** instead of taking several seconds: the password check was rewritten to be much faster (the result is the same).
- **A server's settings are no longer lost when an NPV export is opened.**
  - The text `"false"` was read as true: a TLS server was made *insecure* (its certificate was not checked) and a gRPC server was made *multi*. Now only `true` and `1` count.
  - The *final mask* (fragmenting of the TLS hello, noise) was dropped. It is kept now. A server that has one is carried by Xray when it is used on its own (in the automatic group it stays on sing-box without it).
  - The socket options and the timings of gRPC are kept too.
  - If a record of the file cannot be opened, a warning with their number is shown instead of leaving them out silently.
- The routing, DNS and local-port parts that NPV writes inside each server are not imported: Kumo uses its own.
