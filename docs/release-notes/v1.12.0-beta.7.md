# Kumo 1.12.0 beta 7 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 6

- **VPN Gate servers in Free connections (Windows).** A new card, *VPN Gate servers*, gets the public OpenVPN servers of [VPN Gate](https://www.vpngate.net) and adds them to the servers added by hand (a refresh replaces the earlier ones). vpngate.net cannot be opened from Iran, so the list is copied every 3 hours to a GitHub repository ([AbolDev/vpngate-mirror](https://github.com/AbolDev/vpngate-mirror)) and Kumo takes it from GitHub and its mirrors. Nothing in the list is filtered, so some servers will not connect. VPN Gate's servers are run by volunteers and may keep logs: do not use them for anything private.

OpenVPN is as in beta 4 (a test feature, Windows only for now).
