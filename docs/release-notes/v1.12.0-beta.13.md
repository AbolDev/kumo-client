# Kumo 1.12.0 beta 13 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 12

- **Anonymous usage count: more detail, and Windows 11 is told apart from 10.** With the daily count Kumo now also sends the language chosen in the app and the device's language and country setting (not where you are), the time zone, the processor, the name of the release file that was installed (for example `kumo-android-universal.apk`), and on Android the phone's maker, model and interface. The last message sent when you turn the switch off carries none of these. Windows 11 used to be counted as Windows 10 (both report 10.0); it is now told apart by its build number. The list is in the [privacy policy](https://github.com/AbolDev/kumo-client/blob/main/PRIVACY.md); the switch is in *Settings → App settings*.
