# Kumo 1.12.0 beta 10 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 9

- **OpenVPN on Android.** Add an `.ovpn` file (or take servers from *Free connections > VPN Gate servers*) and connect like any other server. The official OpenVPN program (2.6.14, with OpenSSL, LZO and LZ4) runs as a service of its own: it carries the whole connection, so sing-box's routing options (bypass lists, ad blocking) do not apply while it runs. Per-app routing, the kill switch and the notification with speed work. A login the server asks for is asked in a window, and a login a file does not mention can be given there too.
  - Tested on an emulator against a local OpenVPN server (connecting, traffic through the tunnel, disconnecting, a refused login, a timeout). It has **not** been tried on a phone, nor on arm CPUs, nor with a public server.
  - Not repeated by the tile, the widget or the device-startup receiver (the app opens instead). *Keep the proxy running* and the automatic mode do not use OpenVPN servers. Old ciphers such as BF-CBC are not supported. *Real delay* does not work on the phone (the TCP/UDP ping does).
- **Fix: a server that wants a login its file does not mention** (it answered AUTH_FAILED) now gets the login window with its fields, and the login is used (Windows and Android).
- **Fix: real delay of OpenVPN servers** no longer counts a server that refuses the login as working.
