# Kumo 1.12.2 beta 5 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 4

- **Faster to connect.** A connection no longer waits for any list to download. The lists there are used, and the ones missing are stood in for by lists that now come with the app (the countries of *Direct countries*, and the ad list that was already there). They are refreshed a few seconds after the connection is up, through it. Lists are read and merged in the background, so the screen does not stop, and the big ones are kept in sing-box's binary format, which the core reads several times faster and with less memory. Server names are looked up over Cloudflare and Google at once, and ahead of time while Kumo is open and not connected.
- **Faster to disconnect.** On Android a disconnect no longer waits for open connections to close or for tests in progress; on the desktop it is shown at once and the rest finishes in the background. On Windows the system proxy is set through the registry directly instead of a program for each value. The screen can no longer stay on *Disconnecting*.
- **Find a clean IP, redesigned.** A setup, a scan and a results view instead of one long form. Up to 10,000 addresses (was 500), picked with buttons together with the timeout, with a hint of how long it can take; a progress card during the scan; results you can sort by speed, loss or download speed, with the latency in color; an action bar to add the ticked addresses to configs or put one in place of a config's address; the copy options in the top menu.
- **Ad blocking.** A few more trackers that the test pages found (Samsung's and RudderStack's).
- **Free connections.** The VPN Gate card is laid out like the others; its text no longer runs down in a narrow column.

Everything else is as in [beta 1](https://github.com/AbolDev/kumo-client/releases/tag/v1.12.2-beta.1) to beta 4. Most of it was checked by tests, not on every kind of device, so please tell us what you see.
