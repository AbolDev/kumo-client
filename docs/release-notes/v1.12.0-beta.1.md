# Kumo 1.12.0 beta 1 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings. **Windows only for the new part.**

## What's new

- **OpenVPN (Windows, a test feature).** Kumo can now connect through an OpenVPN server.
  - Add an `.ovpn` file (from the **+** menu: *Add from file* or *Add from clipboard*, with the certificates inside the file). It becomes a server of the type *openvpn* in *Added manually*.
  - A file is never run as it is. Kumo reads the lines it knows and writes its own configuration; lines that run programs (`up`, `down`, `route-up`, `plugin`...), open a control port, write files or load other files are left out.
  - If the server asks for a user name and password, a *OpenVPN login* window opens (also in the menu of the server).
  - Kumo runs the official OpenVPN (signed by OpenVPN Inc., in the `openvpn` folder) and sends everything out through its adapter, so the rules, the DNS, the speed and the usage work as with other servers.
  - **The network driver is not part of Kumo.** OpenVPN needs *TAP-Windows*, which the official OpenVPN installer from openvpn.net/community-downloads adds. Without it Kumo says so and does not connect.
  - Not yet: Linux, macOS and Android, tests of the servers' delay, and the *keep the proxy running* mode.
- **A new public list.** The list of F0rc3Run (a couple of hundred tested servers) is added to *Public servers*.

## About this test

OpenVPN was tested up to the point of starting the program, the management port, the login, and the sing-box configuration (accepted by the real core). It has **not yet been tried against a real server** in a build of the app: please report what you see (the log page shows the messages of OpenVPN).
