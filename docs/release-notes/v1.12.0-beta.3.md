# Kumo 1.12.0 beta 3 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings. **Windows only for the new part.**

## What's new since beta 2

- **OpenVPN: the adapter is made with the right driver.** Beta 2 could stop with "could not be installed" on a computer where OpenVPN's other driver (*ovpn-dco*) is installed: the adapter that was made then was of that kind, which cannot carry most configurations. Kumo now always asks for a TAP-Windows adapter by name, takes away one of its own that an earlier run made with another driver, and puts the TAP driver in Windows only when it is really missing. A package that Windows already had is no longer counted as a failure.
- **The notice tells what went wrong.** It had a `{detail}` that was not filled in; it now shows the first lines of what Windows or OpenVPN said.
- **Flags on the "What is my IP" page** are shown as pictures on Windows and Linux (Windows showed the two letters of the country).

## OpenVPN (a test feature, Windows)

- Add an `.ovpn` file (from the **+** menu: *Add from file* or *Add from clipboard*, with the certificates inside the file). It becomes a server of the type *openvpn* in *Added manually*.
- A file is never run as it is. Kumo reads the lines it knows and writes its own configuration; lines that run programs (`up`, `down`, `route-up`, `plugin`...), open a control port, write files or load other files are left out.
- If the server asks for a user name and password, an *OpenVPN login* window opens (also in the menu of the server).
- Kumo runs the official OpenVPN (signed by OpenVPN Inc., in the `openvpn` folder, with the TAP driver beside it) and sends everything out through its adapter.
- Not yet: Linux, macOS and Android, tests of the servers' delay, and the *keep the proxy running* mode.

## About this test

It has **not yet been tried against a real server** in a build of the app: please report what you see (the log page shows the messages of OpenVPN).
