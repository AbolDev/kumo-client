# Kumo 1.12.2 beta 3 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 2

- **A clearer icon in the status bar (Android).** The notification icon is the app icon's cloud again, with its facets shown as shades. If your phone draws it as a plain white cloud, tell us which phone it is.

Everything else is as in [beta 1](https://github.com/AbolDev/kumo-client/releases/tag/v1.12.2-beta.1) and beta 2: crash reports, opening links and files with Kumo (also on macOS), a User-Agent and headers for a subscription, *Find the best settings for my network*, the WARP scans and Warp-in-Warp, encrypted lookup of server names, the Android kill switch and Always-on VPN, *Find a clean IP*, and the request for a star. Most of it was checked by tests, not on every kind of device, so please tell us what you see.
