# Kumo 1.12.0 beta 5 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 4

- **Disconnect works again on Windows.** In beta 4, pressing *Disconnect* while connected disconnected and then connected again at once. The stop now ends there, and a stop that gets no answer puts the screen back after a few seconds.

OpenVPN is as in beta 4 (a test feature, Windows only for now).
