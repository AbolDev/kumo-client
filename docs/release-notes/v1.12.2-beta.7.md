# Kumo 1.12.2 beta 7 (test version)

This is a test version (pre-release). It is not offered as an update unless *Include pre-releases* is on in Settings.

## What's new since beta 6

- **The actions on all servers are back in the menu of three dots.** Ping all, real delay, clear results, update subscriptions and *Cancel test* (while a test runs) are menu items again; the bar of buttons above the list is gone. The progress of a test under each group, swiping a server and picking several with a long press stay.
- **The notes of an update are shown with their formatting.** Headings, lists, bold, italic, code and links are drawn, not shown as `**`, `[text](address)` and the like; a link opens in the browser.

Everything else is as in [beta 1](https://github.com/AbolDev/kumo-client/releases/tag/v1.12.2-beta.1) to beta 6. Most of it was checked by tests, not on every kind of device, so please tell us what you see.
